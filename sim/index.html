About this simulation. This is not Amazon Alexa. The conversation is voiced by an AI language model (the model named by the server, served by its provider) acting as a simulated Alexa+ host. Spoken replies are synthesized by Google's Gemini API (a text-to-speech model); when you use the microphone, the recording is sent to Google's Gemini API (a transcription model) to be turned into text and is not stored by this server. What you say or type is sent to the model provider to generate the reply. Reflection prompts come from a rule-based question bank and, when you give a birth profile, from a rule-based Four-Pillars (saju) calculator. It is for reflection and entertainment — not a prediction of the future, and not medical, psychological, legal, or financial advice. Journal entries are stored on the server under this browser's profile id until you delete them with the button above. Intended for ages 13 and up.
